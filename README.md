# SpeechHub2 (Django + SQLite)

Готовый MVP-сайт на Django с тремя разделами:
- **Блог** со статьями и комментариями.
- **Маркетплейс** логопедических материалов (локальные файлы).
- **Форум** с категориями, темами и ответами.

Также реализована **оплата-заглушка**: заказ, вывод реквизитов, загрузка чека и перевод заказа в статус ожидания подтверждения.

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install django pillow
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

## Что уже есть

- SQLite по умолчанию (`db.sqlite3`).
- Регистрация, логин/логаут.
- Личный кабинет (мои товары и мои заказы).
- Создание статей, товаров, тем форума.
- Покупка товара и отправка подтверждения оплаты.
